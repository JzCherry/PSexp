# 导出预设

导出预设用于保存多套有名称的导出参数。先选板块，再选预设，确认参数后点击导出；切换、保存、复制、恢复预设都不会执行导出，也不读取或启动 Photoshop。

## 四个板块分别管理

| 板块 | 预设保存的专属选项 |
| --- | --- |
| 快速导出 | 图片名称 |
| 画板导出 | 全部/选中画板、子目录方式 |
| 图层导出 | 一级图层/图层模式、选中/全部、命名前缀、带文档名前缀、使用当前文档名 |
| 切片导出 | 切片前缀、切片文件夹 |

四个板块的预设都保存 JPG/PNG、JPG 质量和重名处理选项。画板导出的“全部”和“选中”属于同一板块，范围作为预设参数；切回画板板块会恢复之前的范围。为便于提前配置，未打开文档时也可以进入四个板块，但真正导出仍要求相应文档、画板或切片有效。

每个板块都有不可更新、重命名或删除的“默认预设”。默认格式 JPG、质量 80、自动重命名开启；位置为文档目录，命名为空；画板为全部/直接输出，图层为一级图层，切片文件夹为空。应用默认预设是用户明确的恢复操作，不会在升级时自动抹掉旧参数。

首次使用时保留原来的设置，入口显示“当前设置”。自定义预设只出现在所属板块；同一板块禁止同名（忽略大小写、去掉首尾空格），不同板块可使用同名预设。名称 1–40 个字符，禁止控制字符。“默认预设”为内置保留名称。自定义预设总数上限 200。

## 保存、修改与恢复

1. 调整当前板块的选项，点击“保存”，填写名称并确认。
2. 如果当前选中的是自定义预设，修改后入口显示“已修改”，行内按钮变为“更新”；点击才覆盖这个预设。
3. “更多 → 另存为预设”保存当前参数为新的方案。“复制为新预设”同样以当前工作参数打开保存编辑器，并给出副本名称；临时调整会包含在新方案中。
4. “恢复已保存参数”放弃该预设拥有字段的临时调整。默认预设也可恢复，但不能更新原始定义。
5. 重命名只改名称。删除需要在编辑区再确认；仅移除保存的方案，当前导出参数保持不变，入口回到“当前设置”。

保存时可以选择：

- **包含位置**：开启时保存文档目录/桌面/自定义的选择；仅自定义位置保存固定路径。关闭时，应用预设不会更改当前输出位置，分享文件中也不写入原路径。应用文档目录或桌面预设不会清空用户原先缓存的自定义路径。
- **包含命名**：开启时保存当前板块的图片名或前缀及相应文档名选项；关闭时，应用预设保留当前命名，分享文件也不包含被排除的名称。

切片文件夹属于切片专属输出结构，始终保存；“包含命名”管理的是切片文件前缀，不影响切片文件夹。预设保存“使用当前文档名”的规则，不绑定某个实际文档名、文档 ID、画板 ID、图层 ID 或选中对象。选择“选中图层/画板”表示导出时使用 Photoshop 当时的选择。

“已修改”只比较这个预设实际拥有的字段：未包含位置时，换位置不算修改；未包含命名时，改名称不算修改；其他板块的隐藏参数不参与比较。修改不会自动覆盖保存的预设。

## 独立记忆与回退

每个板块独立记忆选中的预设和整套工作参数，包含尚未更新进预设的临时调整。切到其他板块再回来，或保存记忆后重启，会恢复继续编辑的状态。现有参数记忆仍使用合并保存；批量应用预设时暂缓中间写入，完成后保存最终结果。

数据位于设置目录（通常 `%APPDATA%/PsExporter/`）的 **export-presets.json**，与旧的 settings.json 分开。文件包含版本号、自定义预设列表和四个板块的工作状态。临时文件写完后原子替换；读到损坏或不支持的数据时，写新数据前先保留原文件备份。界面主题、窗口位置、收纳、托盘、更新选项均不属于预设。

独立文件让回退代码后，旧版保存 settings.json 时不会顺带清空预设。预设功能分支为 `feature/export-presets`；开发前提交为 `0de9a7e`，备份分支为 `backup/before-export-presets-20261102`。停止测试软件、确认工作区已提交后，可切回备份分支并重新编译体验旧行为；以后切回功能分支，预设文件仍保留。Git 回退源码不会自动回退已经编译的 EXE，需要重新编译。

## 导入与导出

“更多 → 导出本板块预设”导出当前板块全部自定义预设为 JSON；内置默认预设不导出，没有自定义预设时此项禁用。文件仅包含预设定义，不含工作区临时调整、应用偏好或文档数据。未勾选的位置/命名及其他板块的无关字段会从预设参数中清除。

导入文件可以包含多个板块的预设，按所属板块自动归类；不切换当前板块、不应用参数、不覆盖已有方案。导入的 ID 重新生成，同名名称追加 `(2)` 等后缀。先校验整批文件，再合并；格式、版本、数量或参数错误时整批拒绝。支持 UTF-8 JSON（可带 BOM），最多 1 MB、200 个定义。

文件标识为 `kind: PSexp.export-presets`，版本为 `version: 1`，列表字段 `presets`。每个定义含 id、name、category、includeDestination、includeNaming 和 parameters；枚举按当前 C# 数字序列存储，版本不支持时不猜测转换。名称、分类、枚举值、质量范围会校验，不能把任意 settings.json 当作预设导入。

## 原理与开发入口

- `Models/ExportPresets.cs`：四板块、纯用户参数、预设定义与工作区状态。参数模型独立于实际导出任务，避免带入当前文档和运行数据。
- `Services/ExportPresetCatalog.cs`：分类、内置默认、字段归属比较、可分享字段过滤、导入校验、重名合并。
- `Services/ExportPresetsStorage.cs`：独立 JSON、读取兼容、原文件保护和原子保存。
- `ViewModels/MainViewModel.Presets.cs`：四个工作区切换、预设 CRUD、临时修改、编辑器状态与参数应用。应用只改 VM 参数，不调用 Photoshop 服务或导出服务。
- `Views/ExportPresetBar.axaml`：一个选择入口、保存/更新、更多菜单与按需展开的编辑区。沿用连续曲率、现有主题和分段按钮；关闭在左、开启在右，无滚轮切换。
- `Views/ExportPresetBar.axaml.cs`：选择后的菜单关闭、局部输入焦点、系统 JSON 文件选择。只在当前窗口有焦点时聚焦名称输入框，不注册全局快捷键。
- `tests/PSdodo.PresetTests`：隔离设置的真实 VM 验证，不使用用户设置，也不调用 Photoshop。运行 `dotnet run --project tests/PSdodo.PresetTests -c Release -p:PublishSingleFile=false`；可追加图片目录参数渲染窄宽布局和深浅色组件。

当前已验证保存与恢复、分组隔离、空切片前缀、画板范围共享、重启恢复未保存修改、默认只读、删除不改参数、排除字段不写入分享文件、导入重名和非法文件保护，以及旧版设置写入后保留预设。文件选择对话框和下拉菜单的实际桌面交互仍需用户试用反馈；组件渲染检查不等同于完整桌面操作验收。
