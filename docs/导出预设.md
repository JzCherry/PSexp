# 导出预设

当前界面用“画布合成 / 图层素材”表示原“一级图层 / 图层”，共用“选中 / 全部”范围。两种方式均支持排除前缀；只有画布合成公共复用可见排除项。具体交互、无效选择提示与数据兼容见 [图层导出交互](图层导出交互.md)。

预设是一套有名字的完整导出选项。先选板块和方案，再点击导出；新建、选择、更新、复制、重命名、删除均不执行 Photoshop 脚本或导出任务。

## 最常用的操作

| 目的 | 操作 | 结果 |
| --- | --- | --- |
| 保存当前参数为一个方案 | 点击加号（新建预设），填名称，保存 | 新方案保存完整选项并成为当前方案 |
| 使用已有方案 | 点击行内下拉选择器，再选方案 | 应用该方案的完整选项，列表高亮当前方案 |
| 修改当前方案 | 在下方修改参数，再点更新图标（悬停显示“更新预设”） | 覆盖当前方案的选项，名称保持不变 |
| 从现有选项另建方案 | 点击加号，或更多中的“复制为新预设” | 保留原方案，用当前工作参数建立新方案 |
| 改方案名字 | 更多 → 重命名 | 只改名称，不覆盖尚未保存的导出参数 |
| 删方案 | 更多 → 删除，再确认 | 删除方案，当前导出参数保留 |

界面上“新建”始终是新建，“更新预设”始终是覆盖，不再让同一个按钮根据所选方案换一种含义。平时预设卡片只占一行，不常驻显示状态说明。未选择方案时显示“选择预设”（列表为空时显示“暂无预设”）；有未保存修改时名称旁显示“*”并出现更新图标，悬停提示解释其含义。只有参数与方案有差异且未打开编辑区时才显示更新按钮。状态与完整名称也可通过选择器悬停提示查看。导出使用当前界面参数，不要求先保存预设。

## 从外部运行导出

「设置 → 外部调用」可以复制按当前参数或当前预设导出的 PowerShell 指令。也可以在导出页使用「预设 → 更多 → 复制导出指令」。复制的指令使用预设 ID，重命名后仍然有效；删除预设后，原指令不再有效。外部工具也可分开填写程序路径和参数。

```powershell
# 按当前界面参数导出
& 'C:\Tools\PSexp.exe' --export

# 按板块与预设名称导出
& 'C:\Tools\PSexp.exe' --preset layers '商品图'

# 「复制导出指令」生成的形式
& 'C:\Tools\PSexp.exe' --preset-id 'default:Layers'
```

板块标识为 `quick`（快速）、`artboards`（画板）、`layers`（图层）、`slices`（切片）。程序路径请换成当前 EXE 的实际位置。预设导出使用已保存的设置和当时的 Photoshop 文档/选择，不切换当前板块或覆盖未保存的工作参数。

已有 PSexp 实例时，命令转交同一 Windows 用户及会话的主进程，不主动打开收纳或托盘窗口。未运行时正常启动并提交导出。调用工具和 PSexp 应使用相同的运行权限。正在处理任务或找不到预设时拒绝请求；结果在任务状态和 `%LOCALAPPDATA%\PSexp\Logs\psx.log` 中查看。

短命调用进程的退出码 `0` 表示主进程接收任务，`2` 表示参数无效，`3` 表示转发失败或主进程拒绝。接收不代表文件已导出；首次启动会进入正常应用生命周期。yuSnip、Quicker 等可以将同一条命令绑定到其按键或动作。

## 切换与取消

修改方案后，改动先作为当前工作参数记忆，不会自动覆盖方案定义。选择另一份方案（或重新选择当前方案）直接应用其已保存参数并关闭下拉菜单，不弹确认、不显示切换提示。未更新的临时参数会被所选方案替换；需要保留时，应在切换前点击更新图标，或点击加号另建方案。

切换快速/画板/图层/切片板块本身不丢弃参数，各板块独立记忆当前方案和临时调整。画板的全部/选中属于同一工作区。关闭软件、切换板块、取消编辑均不等同于更新预设。

下拉菜单点外部或 Esc 可关闭。名称输入框的右键菜单优先处理；点击复制、粘贴或关闭右键菜单不会误取消预设编辑。新建/重命名取消后不创建、不更名；删除取消后不删除。名称允许 1–40 个字符，去首尾空格，同板块不允许重名，不同板块可同名。

## 默认预设也是普通方案

初次建立预设库时，每个板块提供一份“默认预设”：JPG、质量 80、重名自动改名、文档位置；画板为全部/直接输出，图层为一级图层，切片文件夹为空。它可更新、复制、更名、删除，没有特殊的只读权限。“默认”只是初始名称，不表示恢复出厂或自动覆盖个人设置。

默认方案只创建一次。状态中的 defaultsInitialized 记录初始化已经完成；删除一份或删空整个板块，重启都不补回。删除最后一份时保留当前选项，可随时点击新建。第一次启用功能仍保留原有导出参数，不强制应用默认方案。四板块合计最多 200 个方案，初始默认也计数；旧库已达上限时不强塞默认方案。

## 每份方案保存什么

所有方案保存格式、JPG 质量、卡片标题右侧“自动改名”按钮的重名处理状态、输出位置类型，以及本板块的专属选项。

| 板块 | 专属内容 |
| --- | --- |
| 快速导出 | 图片名称 |
| 画板导出 | 全部/选中画板、直接输出/文件夹方式、文件前缀 |
| 图层导出 | 一级/图层模式、选中/全部、文件前缀 |
| 切片导出 | 切片前缀、切片文件夹（空值也保存） |

**位置和命名始终保存，没有可排除的开关。** 方案选择自定义位置时保存实际路径；文档位置/桌面保存位置规则，不把当前解析出的实际目录写成固定路径。再次应用文档位置时使用当时文档目录，桌面使用系统真实桌面目录。非自定义方案不会清空缓存的自定义路径，该缓存也不影响已保存状态。

命名保存填写内容或使用文档名的规则；不是把某个当前文档、图层 ID、画板 ID 或实际选中对象固定下来。选择“选中图层/画板”表示导出时使用当时的 Photoshop 选择。改动本板块位置、命名、范围等会显示修改未保存，其他板块隐藏的无关字段不参与比较。界面主题、窗口位置、收纳、托盘、更新选项均不属于导出预设。

## 旧预设如何兼容

旧版“包含位置”关闭表示应用时保留原输出位置；“包含命名”关闭表示保留原名称/前缀。因此旧版同一预设可能随当前参数产生不同结果，新界面去掉这种部分覆盖行为。

升级读取旧库后，已保存的参数继续保留。对旧方案未包含的位置/命名，使用该方案所属板块记忆的工作参数补齐一次，并显示迁移提示；不是声称恢复了从未保存过的历史值。迁移后的方案全部按完整选项工作，两个兼容布尔字段写为 true。迁移写入前先备份原 export-presets.json，便于人工回退数据。默认方案的定义从即时合成改为真实记录；已初始化标记与删除一起持久化。

## 数据、实现与回退

数据位于设置目录（通常 %APPDATA%/PsExporter/）的 export-presets.json，与 settings.json 分离。version 保持 1，新增 defaultsInitialized 标记。items 保存方案定义，workspaces 保存四个板块选中方案 ID 和当前完整工作参数。读取校验分类、名称、ID、枚举等；保存先写 .tmp 后原子替换，读取异常时先备份原文件再允许新写入。备份名带 UTC 时间。旧版重写 settings.json 不会直接删除独立预设文件；回退到旧版预设实现可能按旧的只读/部分保存语义处理数据，必要时同时恢复迁移前的数据备份。

- Models/ExportPresets.cs：参数、方案、工作区、初始化标记；IncludeDestination/IncludeNaming 仅保留兼容旧 JSON，当前 UI 不暴露。
- Services/ExportPresetCatalog.cs：默认初始定义、参数归属、比较、规范化、旧部分方案补齐。IsBuiltIn 仅识别旧 ID 前缀，不再代表只读权限。底层旧 JSON 导入校验方法保留兼容开发调用，产品界面没有导入/导出入口。
- Services/ExportPresetsStorage.cs：独立存储、原子替换与迁移前备份。
- ViewModels/MainViewModel.Presets.cs：默认只初始化一次、完整选项应用、编辑状态、直接切换、参数记忆。默认查找与其他方案一致，不再每次生成只读默认。
- Views/ExportPresetBar.axaml：单行预设栏、加号新建、行内修改标记与更新图标、局部名称/删除编辑区。下拉列表每项 32 DIP、间距 2 DIP；左侧名称，选中状态用整行淡蓝底高亮，右侧格式/质量，详细范围在悬停提示。列表宽度跟随选择器且限制为 200–300 DIP，滚动区最高 224 DIP；不再按整张卡片宽度铺开。
- Views/ExportPresetBar.axaml.cs：菜单关闭、输入焦点和编辑区外部取消；使用当前窗口内事件，无全局按键钩子。
- tests/PSdodo.PresetTests：原有隔离验证已随行为改动更新。此次按用户要求不运行自动或 Photoshop 交互测试，仅编译检查，具体界面手感由用户试用。

当前开发分支为 feature/export-presets，原始功能开发前基线为 0de9a7e，备份分支 backup/before-export-presets-20261102。当前重设计前完整源码另已备份在项目外层的备份目录，包含此前尚未提交的菜单、输入框和路径布局修复。切换代码后需要重新编译，Git 不会自动替换已经运行的 EXE。



画板、图层、切片的前缀统一由 FilePrefix 保存，输入框有文字才添加“前缀_”，清空等于不加；不再有模式开关或文档名兜底。三板块分别记忆，前缀修改会显示预设未保存，重新选择预设恢复其中的前缀（包括空值）。旧切片参数 SlicePrefix 和旧图层自定义 ImageName 读取时转换到 FilePrefix；旧文档名自动模式取消，旧画板前缀默认空。旧版本数据转换前先备份原预设 JSON，回退旧软件时按需同时恢复旧数据。
