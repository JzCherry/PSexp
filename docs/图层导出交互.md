# 图层导出交互：画布合成与图层素材

本分支 `feature/layer-export-clarity` 从 `d69443d` 创建。界面只保留“导出方式”和“导出范围”两个决定，格式、质量、输出位置、命名与预设共用，不新增排除开关。

## 两种方式怎么解释

| 界面名称 | 旧称及实现参数 | 导出什么 | 适合什么 |
| --- | --- | --- | --- |
| 画布合成 | 一级图层；LayerExportRecursive=false | 每个最外层图层/组分别作为主体，保留完整画布，与有效可见公共内容合成 | 多方案套图、统一水印/底图、相同坐标的交付图 |
| 图层素材 | 图层；LayerExportRecursive=true | 按 Photoshop 原生图层/组内容边界输出 | 组件、图标、图片等独立素材 |

“选中 / 全部”共用一份范围。切换方式不改范围、格式、质量、目录或前缀；选择其他预设时仍按预设恢复整套参数。“全部”在画布合成中指全部合格根级对象，在图层素材中指全部合格叶子图层。选中组在素材方式中整体输出，组和子层同时选中只输出组，避免重复。

## 排除是一条规则，不是另一个功能模式

两种方式均识别名称开头的“排除”，整组排除会传递到子层，手动选中不绕过。它表示“不作为独立导出目标”，不表示强制隐藏，也不表示从选中组的整体内容中删掉该层。真正背景按 isBackgroundLayer 判断，同样不独立导出。

画布合成会保留背景与排除项原有可见性，因而可见项能作为公共水印、边框、底图；隐藏项保持隐藏，父组、叠放与 Photoshop 混合规则仍会影响结果。图层素材不把外部公共背景/水印合入，但选中组仍整体包含组内有效内容。素材的具体尺寸与复杂效果以 Photoshop 原生导出为准。

## 无效选择的反馈

| 选择情形（范围为选中） | 行为与提示 |
| --- | --- |
| 只选“排除”开头的图层/组 | 不执行导出，点名该对象和原因；提示改选普通对象，或先移除对象及祖先的排除前缀 |
| 只选排除组里的子层 | 不执行导出，提示“位于排除组内”；只改子层名称并不能解除父组排除 |
| 画布合成只选普通组里的子层 | 不自动扩大成整组；提示选最外层组，或切换图层素材 |
| 只选真正背景 | 不执行导出，提示背景不单独导出及改选普通对象 |
| 合格对象与无效对象混选 | 导出合格项；任务完成文案同时显示跳过数量、示例名称与原因，写入 Warn 日志 |
| 素材方式选中组和该组子层 | 只把组作为目标；属于去重，不另报无效选择 |

详情最多展示三个名称示例，每个名称最多四十字符；数量为完整统计。范围为“全部”时按规则遍历，当前选择不影响结果，不为主动排除项逐个发警告。跳过是跳过独立目标，不是把选中组整体内容里的该层强制隐藏。导出失败与成功跳过在任务区明确区分，不以无效选择回退到全部导出。

## 参数记忆与旧数据

新增 nullable layerScopeSelectedOnly。旧设置/旧预设缺少该字段时，按其当前导出方式读取旧 layerExportSelectedOnly 或 layerTopLevelSelectedOnly，不盲目使用默认值。之后两种方式使用同一范围，并同步旧字段用于兼容。预设缺少新字段时原文件先备份再保存标准化数据；默认仍是画布合成/全部。不保存文档选择的图层 ID，不因记忆而操作 Photoshop。

## 源码依据

- layer_targets.psjs：共用遍历、排除继承、根级/叶子/选中筛选、无效原因及混选警告。
- ScriptLibrary.ComposeLayerTargets：为 layer_batch 与 native_layers 拼入同一目标规则，不让两种规则各自演变。
- layer_batch.psjs：画布合成保存副本与恢复可见性；不改为按主体裁边。
- native_layers.psjs：临时选定有效目标，调用原生 exportSelectionAsFileTypePressed 并恢复原选择；不复制裁剪文档。
- receipt_task.psjs：把 warning 传回应用，后台文件完成仍由现有文件检查确认。
- MainViewModel.LayerExport.cs：解析本次回执警告；任务区和日志展示跳过原因。
- ExportPresetCatalog / ExportPresetsStorage：旧范围解析、统一范围与备份迁移。

本次按用户要求不运行软件、Photoshop 或自动化测试，只检查编译与代码差异。取消、强退以及 Photoshop 原生命令对复杂图层的处理仍需实际验收，不承诺任意图层都能无依赖地还原整体效果。
